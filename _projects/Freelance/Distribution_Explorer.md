### Project Overview

The **Distribution Explorer** is an interactive statistical visualization tool designed to make probability distributions more intuitive and accessible. Built with **React** and **Vite**, the application allows users to explore how key parameters influence the shape, spread, and behavior of common statistical distributions in real time.

This project was created to bridge the gap between theoretical statistics and practical understanding by transforming static textbook visuals into dynamic, user-driven exploration.

### Key Outcomes

- **Interactive Parameter Manipulation:** Users can adjust distribution parameters (mean, variance, etc.) and instantly visualize their impact.
- **Concept Reinforcement:** Helps build intuition around distribution behavior such as skewness, spread, and central tendency.
- **Educational Utility:** Designed as a teaching aid for statistics students and practitioners looking to deepen conceptual understanding.
- **Reusable Visualization Components:** Built modular charting components for future expansion into additional statistical tools.

### Technical Implementation

- **React State Management:** Drives real-time updates of distribution curves based on user input.
- **Vite Build System:** Enables fast development cycles and optimized production builds.
- **Dynamic Rendering:** Efficiently updates visualizations without full re-renders, ensuring smooth interaction.
- **Component-Based Architecture:** Designed for scalability to support additional distributions and features.
