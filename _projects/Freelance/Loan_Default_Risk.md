### Project Overview

This project explores the statistical and machine learning foundations of **loan default risk prediction**, focusing on identifying borrower characteristics associated with increased probability of default. The analysis was designed to demonstrate an end-to-end applied data science workflow — from exploratory data analysis and feature relationships to predictive modeling insights.

Using Python-based analytical tools, the project evaluates financial, demographic, and behavioral variables to understand how borrower attributes interact and contribute to credit risk. Emphasis was placed on interpretable analysis, visual diagnostics, and communicating model-driven insights clearly to non-technical stakeholders.

Exploratory visualizations were used to uncover multivariate relationships, detect correlation structures, and guide feature understanding prior to modeling. The analysis ultimately illustrates how statistical reasoning and machine learning techniques can support data-informed lending decisions and risk assessment strategies.

### Key Outcomes

- Identified primary variables associated with elevated loan default risk
- Demonstrated structured exploratory data analysis to guide modeling decisions
- Evaluated relationships between borrower financial indicators using multivariate visualization
- Produced interpretable analytical outputs suitable for stakeholder communication
- Showcased a reproducible analytical workflow combining statistics and machine learning concepts
